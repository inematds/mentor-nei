# Skills

- Tipo: tema

## O que ele sabe

Skill é a receita/manual que o agente pode usar. Ajuda, mas precisa de curadoria: descrições pesam no contexto, versões duplicadas competem, skill de terceiros pode trazer risco; prefira skill de projeto e /nome para as raras.

### Por fonte (o que cada lote observou)

- **Skills: uso, excesso e manutenção** — Skills ajudam, mas precisam ser administradas: descrições pesam no contexto, versões duplicadas competem pelo mesmo gatilho, e skills copiadas entre sistemas quebram. As raras devem ser chamadas por /nome.
- **Skills: receita aprovada, curadoria e escopo de projeto** — Skill é a receita que o agente pode usar; uma lista de skills aprovadas reduz alucinação e dá segurança. Ele avisa que baixar skill de terceiros pode trazer vírus, faz curadoria das que usa e defende skill de projeto em vez de global para não pesar no contexto.
