## O que ele sabe

Base antes do vibe code: terminal, pasta de projetos, chaves SSH, onde roda cada coisa (local, Vercel, VPS), CPU x GPU, portas, firewall, túnel SSH e API interna fechada.

### Por fonte (o que cada lote observou)

- **Infraestrutura básica (terminal, pastas, SSH, VPS, CPU x GPU)** — Base que vem antes de qualquer vibe code: terminal, pasta de projetos, chaves SSH, onde roda cada coisa (máquina local, Vercel, VPS persistente) e o custo de CPU x GPU. Ele roda tudo numa VPS e não na máquina local.
- **VPS, portas, firewall e segurança básica** — O app roda em VPS com o front (casca) exposto e a API interna fechada, senha criptografada, script que abre e fecha a porta no firewall, túnel SSH. Para concorrência, fila ou mais workers.
