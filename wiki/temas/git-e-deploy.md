# Git e deploy

- Tipo: tema

## O que ele sabe

Git como versionamento e backup; repo público no GitHub Pages, privado na Vercel com variáveis de ambiente; .env fora do git; publicar termina no push; em produção própria, VPS/Docker atrás de HTTPS.

### Por fonte (o que cada lote observou)

- **Git e deploy (GitHub, Pages, Vercel, VPS)** — Versionar tudo no GitHub e publicar a partir do git: GitHub Pages (main + root) para repo público, Vercel para privado com variáveis de ambiente, diretório raiz e domínio; .env nunca vai pro git; SSH/tokens para autenticar. Em produção própria, Docker numa VPS atrás de proxy HTTPS.
- **Git e deploy (GitHub, Pages, Vercel)** — Git como versionamento e backup (clone/pull/push, branch/merge), repositório público publicado no GitHub Pages (pasta guia/), repositório privado publicado pela Vercel com variáveis de ambiente, e publicação que termina no push.
