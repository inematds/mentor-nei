# Fluxos vs agentes

- Tipo: tema

## O que ele sabe

Agente usa LLM, custa e não é exato; worker/função é determinístico. Skill é uma ação, fluxo é skills encadeadas. Ele usa o agente para construir e fixa o caminho no fluxo para operar barato: menos IA, mais worker.

### Por fonte (o que cada lote observou)

- **Fluxos vs agentes** — Agente usa LLM, custa e não é exato; worker/função é programa determinístico. Ele usa o agente para construir e fixa o caminho (kind agente|função) no fluxo para operar barato.
- **Skill x fluxo x agente** — Uma skill é uma ação; um fluxo é um conjunto de skills encadeadas (ex.: promo avatar no Inema CCBOT). A meta é a aplicação ter menos IA e mais worker determinístico.
