# Auditar e otimizar um site para agentes (Web MCP)

- Tipo: metodo

## O que é

Medir o site com um scanner, pedir ao agente só análise e proposta, ler o relatório com senso crítico e implementar com o projeto versionado no Git.

## Passos

1. Rodar o scanner na URL e anotar a nota (Web MCP, SEO, GEO, AEO)
2. Abrir o repositório do site com o agente (Codex/Claude Code) e passar o prompt de auditoria
3. Pedir explicitamente: não faça nada, só analise e mostre uma proposta
4. Ler o relatório: bloqueadores, alertas e limites da própria nota
5. Aprovar a implementação só com o projeto no Git, para poder voltar atrás
6. Escanear de novo e comparar a nota
