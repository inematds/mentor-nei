# Guia de projeto (landing + guia de uso)

- Tipo: metodo

## O que é

Cada projeto publicado ganha uma página única de landing + guia de uso no próprio repo (GitHub Pages, pasta guia/), com caminho mínimo copiável, comandos reais e saída esperada.

## Passos

1. Abrir com o que é e o problema/número de negócio que resolve
2. Caminho mínimo copiável: clone → instalar/--check → .env → primeiro pedido → conferência
3. Cada passo com o comando real e a saída esperada (exit code, healthy, 0 erros)
4. Separar o que custa/publica (pede confirmação, teto de gasto) do que é local e reversível
5. Roadmap honesto: o que está pronto e exercitado x o que só tem teste de contrato
6. Publicar no GitHub Pages do próprio repo (pasta guia/) — publicar termina no push
